# Support

- **Your Moveworks org's API setup** (enablement, credentials, access tokens, rate limits, feature
  availability): contact your Moveworks account team, or Moveworks Support at
  [support@moveworks.ai](mailto:support@moveworks.ai).
- **How an API behaves**: see the [Moveworks API documentation](https://docs.moveworks.com/api-reference),
  for example the [Eval API overview](https://docs.moveworks.com/api-reference/alpha-eval-api/overview).
- **Bugs or gaps in these plugins**: open a GitHub issue on this repo. Issues are answered on a best-effort
  basis.
- **Security-sensitive reports**: see [SECURITY.md](SECURITY.md). Do not open a public issue.

This repository is provided as-is under its license. It is not a supported Moveworks product and carries no
SLA. The APIs these plugins use can be in alpha or limited availability and their behavior can change; verify
against the [official documentation](https://docs.moveworks.com/api-reference) before relying on them.
